# NITHU FASHION WORLD 👑✨

> **Traditional Craftsmanship For A Brighter You**  
> *Stitching Dreams, Creating You*

A luxury fashion and custom tailoring e-commerce web platform designed with a burgundy, cream, blush, and gold aesthetic.

---

## 🌸 Features

- **Luxury Brand Identity**: Burgundy (`#3D0008` / `#57000D`), Cream (`#FFF7F0`), Blush Pink (`#F3D7CE`), and Royal Gold (`#C89B5A`).
- **Typography**: Cormorant Garamond, Allura Script, and Montserrat.
- **Top Announcement Bar**: Fast delivery across Tamil Nadu, secure online payments, helpline support.
- **Sticky Luxury Navbar**: Search autocomplete, wishlist counter, user account, cart drawer trigger.
- **Hero Section**: Grand typography, bridal saree/blouse model showcase, dual CTAs, and bottom USP strip.
- **Shop by Category**: 8 luxury category cards (*Sarees, Blouses, Dresses & Kurtis, Kids Wear, Tailoring, Art & Crafts, Customized Gifts, Festive Collection*).
- **Our Services**: 4 circular service badges (*Tailoring for Kids & Women, Customized Embroidery, Aari Work, Art & Crafts*) + *"Book a Service"* CTA banner.
- **Featured Collection**: Category filter pills, discount tags, rating stars, quick view, and add-to-cart actions.
- **How It Works**: 4-step workflow (*Choose → Customize → Place Order → We Create & Deliver*).
- **Customer Reviews**: Verified customer testimonials with 5-star ratings.
- **Instagram Gallery**: 7-image interactive grid connected to `@nithu_fashion_world`.
- **Modals & Drawers**:
  - Cart Drawer with quantity management, subtotal, and confetti checkout.
  - Wishlist Drawer for favorite items.
  - Quick View modal with custom sizing options.
  - Book Custom Tailoring consultation modal with WhatsApp integration.
- **Footer**: 5-column burgundy footer with direct phone number (`9585477733`), address (Komarapalayam, Tamil Nadu), and newsletter.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations & Effects**: Framer Motion, Canvas Confetti

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```
